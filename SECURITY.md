# Security

Synchronous Audio Router includes a kernel-mode driver. Please report anything
that could let a local user crash the machine, read or change another
process's audio, or gain privileges.

## Reporting a vulnerability

Use **Report a vulnerability** under this repository's **Security** tab. That
opens a private report that only the maintainer sees. Please don't open a
public issue for a security problem.

## Supported versions

Only the latest release gets fixes. Releases before 0.14.0 are not maintained.
